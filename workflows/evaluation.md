# Evaluation

For meaningful AI, agentic, retrieval, scoring, ranking, parsing, recommendation, or automation changes:

1. Define success measures and a representative baseline before implementation.
2. Keep the evaluation set stable; do not change it just to improve reported results.
3. Report totals, passes, failures, regressions, excluded cases, and reasons.
4. Separate deterministic correctness checks from human or model quality judgments.
5. Label estimates and simulated integrations clearly, and match claims to evidence.
6. Record reproduction steps and remaining uncertainty before calling the evaluation complete.
