# Task Report

Conclude completed work with:

## Changed
What changed and the resulting outcome.

## Inspected
Files, systems, assets, runtime paths, or external records inspected.

## Related Systems
Callers, shared types, validation, configuration, tests, deployment paths, or docs checked.

## Extra Issues Fixed
Related issues fixed because they shared the root cause or were needed for consistency.

## Out of Scope
Issues noticed but left outside the request.

## Verification
Checks run, results, checks omitted, and evidence limits.

## Assumptions and Risks
Assumptions, unavailable checks, and remaining uncertainty.

Finish with `Technologies used this turn: ...` and list the actual tools and technologies used.
