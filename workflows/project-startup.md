# Project Startup

1. Confirm the working directory is inside a real Git repository and resolve its root.
2. Check the root for `AGENTS.md`, README files, manifests, configuration, and other project documentation.
3. Check for `memories.md` when present; use it as background context only.
4. Inspect the current branch, remotes, and dirty state before Git operations that could affect history or files.
5. For a new project or initial design, ask James's technology preference and compare at least two suitable options with project-specific pros and cons.
