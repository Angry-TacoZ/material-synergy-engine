# Deployment Security

- Identify client-visible bundles, server-side secrets, public endpoints, and data trust boundaries.
- Check that authorization and input validation happen at trusted boundaries.
- Keep credentials out of source, browser-delivered assets, logs, and test artifacts.
- Do not deploy with a critical security, privacy, data-loss, or uncontrolled-cost blocker.
- Verify public output against the reviewed source revision before claiming release success.
