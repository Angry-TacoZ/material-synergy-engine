# Review Before Merge

- Read the complete diff and compare it with the request and acceptance criteria.
- Check correctness, regressions, security and privacy, unintended scope, and missing verification.
- Reproduce review findings against current code; do not assume a finding is correct if the code disproves it.
- Resolve actionable findings or clearly report why they remain open before merge.
