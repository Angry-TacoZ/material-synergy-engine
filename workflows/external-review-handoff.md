# External Review Handoff

- State the question the reviewer should answer and the exact commit or diff to inspect.
- Include only the context needed to reproduce and review the change.
- Exclude secrets, private user data, unrelated workspace history, and unsupported claims.
- Preserve the review result and address actionable findings before delivery.
