# Delivery to Release

1. Confirm the requested target and reviewed source revision.
2. Complete relevant canonical verification and inspect the final diff.
3. Identify the rollback or recovery path for material changes.
4. Deploy or publish only when the user has authorized it.
5. Verify the live result and report the deployed revision separately from local or CI evidence.
