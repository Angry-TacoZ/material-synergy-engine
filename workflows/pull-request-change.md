# Pull Request Change

1. Reproduce the issue or establish acceptance criteria.
2. Inspect the full relevant path and make the smallest complete change.
3. Add or update focused regression coverage when appropriate.
4. Run relevant verification and inspect the diff for unrelated edits or sensitive data.
5. Summarize the behavior change, evidence, and known gaps for the PR description.
