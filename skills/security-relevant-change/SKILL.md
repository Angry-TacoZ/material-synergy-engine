# Security-Relevant Change

1. Identify assets, users, trust boundaries, and the sensitive data involved.
2. Trace the complete path through input validation, authorization, storage, logs, and output.
3. Check least privilege, safe defaults, secret handling, and failure behavior.
4. Add focused verification for the security property when appropriate.
5. Report residual risks and avoid claims broader than the evidence.
