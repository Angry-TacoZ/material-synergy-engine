# Interaction Usability

- Identify the intended user action and the feedback that should follow it.
- Check focus, labels, contrast, hit areas, responsive behavior, and error or empty states when relevant.
- Treat pointer and mobile touch as baseline inputs for interactive visual experiences.
- Confirm the actual interaction in the running product; do not infer success from source changes alone.
- Keep product language consistent with the requested behavior.
